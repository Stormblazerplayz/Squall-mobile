# Select messages

Copy, share or star many messages at once.

1. Long-press a message and tap **Select**.
2. Tap other messages to pick them. Each one shows a check circle.
3. Use the bar over the message box: **Copy**, **Share** or **Star** them all, or tap **Done**.

- Copied and shared text says who wrote each message and when, in chat order.
- Your messages and teammates' replies with words can be picked.
- Select mode ends when you tap Done, copy, star, or leave the chat.

Code: `Squall/Models/ChatSelection.swift` and `Squall/Views/Chat/SelectMessages.swift`.
Tests: `SquallTests/ChatSelectionTests.swift`.

# Translate and Message info

Press and hold your message or a teammate's reply:

- **Translate** opens Apple's Translate card with the message's words (no Markdown marks). You can copy the
  translation from there. It needs iOS 17.4 or newer, so older phones don't show it. Apple does the translating on the phone.
- **Info** opens a sheet with who wrote it, when it was sent (full day and time when the computer says), how many words
  and characters it has, about how long it takes to read, and how many links and code blocks are in it.

Code: `Squall/Models/MessageInfo.swift`, `Squall/Views/Chat/MessageInfoViews.swift`, menu items in `MessageMenu`.

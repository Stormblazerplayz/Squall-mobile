# To-dos in this chat

Tap ••• at the top of a chat and pick **To-dos in this chat** to see every task-list line ("- [ ] …") the teammate wrote in that chat, in one place: what's left first, then what's done, with a progress bar on top.

- Tap a line to tick or untick it. The reply it came from changes too, since both use the same ticks (see [Tick task lists](tick-lists.md)).
- Ticking the last one sets off the confetti.
- Press and hold a line and pick Go to message to jump to the reply it's in.

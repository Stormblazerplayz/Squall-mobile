# Copy code and save it as a file

Press and hold a teammate's reply that has code blocks.

- **Copy code** copies just the code, without the words around it. With more than one block you pick a block, or **Copy all code** to get every block with a blank line between them.
- **Save code as a file** opens the share sheet with the block as a file named for its language, like `code-1.swift` or `code-2.py`, so you can save it to Files or send it on. Unknown languages are saved as `.txt`.
- Empty code blocks are skipped.

Code: `Squall/Models/CodePieces.swift`, `Squall/Views/Chat/CodeFile.swift`, `CodeMenu` in `Squall/Views/Chat/StarredViews.swift`.

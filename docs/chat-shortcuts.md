# Chat keyboard shortcuts

With a keyboard on iPad (or iPhone), these work in a chat. Hold ⌘ to see them all.

| Keys | What it does |
| --- | --- |
| ⌘F | Find in chat |
| Esc | Close Find in chat |
| ⌘⇧D | Go to a day |
| ⌘⇧L | Links in this chat |
| ⌘⇧C | Code in this chat |
| ⌘⇧T | To-dos in this chat |
| ⌘⇧P | Problems in this chat |
| ⌘⇧I | Chat stats |
| ⌘E | Open the full editor |
| ⌘⌥↓ | Next chat, in the order of the teammate row (favorites first) |
| ⌘⌥↑ | Previous chat |

These sit next to the app's own shortcuts (⌘1 to ⌘5 for tabs, ⌘R, ⌘N and the rest).

Code: `Squall/Models/ChatShortcuts.swift`, `Squall/Models/ChatBrowse.swift`, `Squall/Views/Chat/ChatKeyCommands.swift`.

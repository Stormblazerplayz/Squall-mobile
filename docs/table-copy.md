# Copy a table

Press and hold a table in a teammate's reply:

- **Copy table**: copies it with tabs between cells, so it pastes straight into Numbers or Google Sheets as rows and columns.
- **Copy as CSV**: copies it as comma-separated text.
- **Save as a CSV file**: shares or saves it as table.csv.

Bold, links and `code` marks are taken off the cells, and short rows get empty cells so every row lines up.

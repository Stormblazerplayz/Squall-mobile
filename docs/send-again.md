# Send again

Press and hold a message you sent:

- **Send again** sends the same words to the same chat right away. If the computer isn't connected, it says so and
  nothing is sent.
- **Edit and send again** puts the words in the message box so you can change them first. Anything you'd already
  typed stays in front of it.

Both live in the press-and-hold menu in `Squall/Views/Chat/StarredViews.swift`.

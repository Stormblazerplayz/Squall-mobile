# Links in this chat

Tap ••• at the top of a chat and pick **Browse this chat** > **Links** to see every web link you or the teammate shared there, newest first. A link shared more than once shows once.

- Tap a link to open it. A link on the computer (like localhost) is copied instead, since the phone can't open it.
- Press and hold for Copy link, Share, or Go to message, which jumps to the message it was in.
- Search by site or any part of the link.
- When a chat has links to two or more sites, a row of site chips shows how many links each site has. Tap one to see only those links, or All to see them all again.
